# HTTP API воркера

**Русский** · [English](../en/api.md)

Воркер — сервис на машине с видеокартой: генерирует треки моделью YuE2, делит их на дорожки, обрабатывает
звук и хранит библиотеку. Приложение Partscaster и MCP-сервер ([mcp.md](mcp.md)) работают только через
этот API. Файл нужен тем, кто пишет свой клиент или скрипт, или разбирается, что именно пошло не так.

## Общее

- Порт — **8091**. Приложение по умолчанию ходит на `http://localhost:8091`; если воркер на отдельной
  машине, адрес задаётся в настройках приложения (например, `http://gpu-host:8091`).
- Аутентификации нет — воркер нельзя открывать в интернет (см. «Безопасность» в
  [README](../../README.ru.md)).
- Ответы — JSON, если не сказано иное. Ошибка — код HTTP и `{"detail": "причина"}`: 404 — нет трека или
  файла, 409 — состояние не позволяет (идёт, уже есть, отменено человеком), 422 — неверный запрос,
  502 — не ответил внешний сервис (GitHub), 503 — компонент не установлен или выключен.
- Загрузка файла — сырые байты в теле запроса, имя — в заголовке `X-Filename`.
- Трек в API называется **джобой** (`job`), `{id}` в путях — её номер. Файлы трека лежат в его папке на
  воркере и отдаются через `GET /audio/{id}/{файл}`.

### Общая очередь

Всё, что занимает видеокарту, идёт по одному, по месту в общей очереди: генерации, `/plan`, превью,
разделение на дорожки, распознавание текста (whisper), транскрипция нот (SheetSage), «голос альбома»,
движок эффектов с усилителем. Тот же список человек видит в приложении.

Запись очереди: `{id, kind, title, job_id, source, state, pos, result_job_id, error, cancel_requested,
client, created_at, started_at, finished_at}`; `source` — `app` / `mcp` / `other` (кто поставил),
`state` — `waiting` / `running` / `done` / `error` / `canceled` / `interrupted`.

Заголовки запроса:

| Заголовок | Значение |
|---|---|
| `X-Partscaster-Source` | `app` или `mcp` — кто ставит операцию (иначе `other`) |
| `X-Partscaster-Op` | id операции клиента (`POST /queue/ops`), внутри которой идёт запрос: шаг цепочки не встаёт в очередь второй раз. Неизвестный id или чужая операция → 409 |

Если человек отменил операцию, тяжёлый шаг отвечает 409 «отменено человеком».

## Служебное и настройки

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/health` | `{status, model_loaded, load_error}` — жив ли воркер, загружена ли модель, ошибка загрузки |
| GET | `/version` | `{version, api, source_hash, model, engine, components: {whisper, seedvc, roformer}, stems_model}`: версия сборки (файл `VERSION` архива, без него `dev`), версия API (клиенты сверяют её со своей), отпечаток кода, модель генерации, движок (`torch` или `cpp-q8` и т. п.), что установлено |
| GET | `/config` | Текущие настройки: `data_dir`, `whisper_py`, `whisper_available`, `seedvc_dir`, `seedvc_available`, `stems_auto`, `auto_stems_instrumental`, `stems_pref` (выбор пользователя), `stems_model` (чем дорожки делаются на деле), `roformer_available`, `fx_engine`, `fx_preview`, `fx_phrases`, `engine`, `cpp_model`, `cpp_low_vram`, `cpp_available` (программа yue2.cpp запускается), `cpp_models` `{имя: {file, size, installed}}` |
| POST | `/config` | Меняет переданные поля, отвечает как GET. Поля: `stems_auto` — когда делать дорожки: `studio` (при открытии студии, по умолчанию; делит клиент), `always` (сразу у каждого готового полного трека и импорта — отдельной операцией очереди после генерации; черновики и куски вклеек — нет), `manual` (иное — 422); `auto_stems_instrumental` — у треков без голоса сразу делать дорожки и проверять, не пролез ли голос (по умолчанию да); `stems_model` — `htdemucs` или `roformer`; `fx_engine` — движок эффектов вкл/выкл; `engine` — `torch` или `cpp` (yue2.cpp, эксперимент), `cpp_model` — `bf16` / `q8` / `q6` / `q5`, `cpp_low_vram`. `engine=cpp` без программы или без скачанной модели — 422. Смена движка — со следующей генерации |
| GET | `/stats` | Сводка для строки состояния: `{model_loaded, vram_total, vram_used (МБ), queue: {queued, running}, running: {job_id, title, stage, progress_pct, tok_per_s}, gpu_waiting}` |
| POST | `/engine/models/install?name=` | Скачать модель yue2.cpp и VAE (`bf16` / `q8` / `q6` / `q5`), закреплённые файлы с проверкой sha256; уже скачанная — без сети. Ждёт конца загрузки → `{name, installed, cpp_models}`. Неизвестное имя — 422, сумма не сошлась или сбой сети — 502 |
| GET | `/engine/models/progress` | Идущая загрузка модели `{name, file, done, total}` или `{}` |

## Очередь

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/queue` | `{paused, items}`: идущая операция, ждущие по месту, последние завершённые (до 20) |
| POST | `/queue/ops` | `{kind, title, job_id}` → запись. Операция клиента — цепочка шагов приложения или MCP (пресет, пересборка). Клиент обязан отмечаться: без `/beat` дольше 180 с операция становится `interrupted` |
| POST | `/queue/ops/{id}/beat` | Отметка «жив» → запись (видно `state` и `cancel_requested`); неизвестная — 404. Необязательное тело `{stage, pass, eta_s}` — ход операции: `stage` — `prepare`, `parts`, `levels`, `render`, `verify` или `fix` (иное — 422), `pass` — номер сборки ≥ 1, `eta_s` — оценка оставшегося, с (≥ 0 или `null`). Без тела последний ход остаётся. Запись отдаёт `stage`, `pass`, `eta_s` и `stage_since` (с с начала шага); у записи без хода — `""`/`null` |
| POST | `/queue/ops/{id}/finish` | `{state: done/error/canceled, result_job_id, error}` → запись; не операция клиента или уже завершена — 409 |
| POST | `/queue/ops/{id}/move` | `{dir: -1 или 1}` → `{moved}`: на место раньше или позже; на краю `moved=false`; не ждёт — 409 |
| POST | `/queue/ops/{id}/cancel` | → `{canceled, running}`: ждущая снимается сразу; у идущей — метка отмены, её внешние процессы (RoFormer, Seed-VC, whisper) останавливаются, шаг внутри воркера доделывается |
| POST | `/queue/pause` | `{paused}` → `{paused}`: новое не начинается, идущая доделывается. Пауза живёт до перезапуска воркера |

## Генерация и треки

| Метод | Путь | Что делает |
|---|---|---|
| POST | `/jobs` | Поставить трек в очередь → `{id}`. Тело — в таблице ниже |
| POST | `/plan` | `{style, lyrics, seed, cot}` → `{abc, truncated, seconds, seed}` — только план (ABC-партитура) без звука. Ждёт свою очередь к видеокарте. `cot=off` — 422 |
| GET | `/jobs` | Список треков, новые первыми, не больше 2000. Фильтров нет |
| GET | `/jobs/{id}` | Один трек. Поля — ниже |
| PATCH | `/jobs/{id}` | `{title?, folder?, parent_id?}` → трек: название (непустое, до 200 символов), папка (до 60; `""` — убрать из папки) и родитель (`parent_id` — существующий трек, не сам этот; иначе 422). Не переданное поле не меняется |
| DELETE | `/jobs/{id}` | Удалить трек и его папку → `{deleted}`; ждущая генерация снимается с очереди; идущий трек — 409 (сначала отменить) |
| POST | `/jobs/{id}/cancel` | В очереди — снять; идущий — остановить генерацию на ближайшем шаге → `{canceled, running?}` |
| POST | `/jobs/{id}/retry` | Упавший или отменённый трек — снова в очередь с теми же параметрами → `{retried}`; другой статус — 409 |
| POST | `/jobs/{id}/continue` | «Продолжение с места» → `{id}`. Тело `{from_sec, seed?, abc?, style_add?, to_sec?, title?}`: новый трек = шаги модели исходника до `from_sec` + продолжение (другой сид — другой вариант; `abc` — изменённый план; `style_add` — приписка к стилю: что изменить в звучании). С `to_sec` — «кусок» (`role=fragment`): модель играет только до `to_sec` (не дальше конца трека) + 2 с хвоста. Новый трек — вложение исходника (`parent_id`, `role=continue`, `cont_from`). 422 — у трека нет шагов модели (импорт) или `from_sec` за концом |
| POST | `/jobs/{id}/head` | `{head_id?}` — основная версия песни: `{id}` — корень, `head_id` — он сам или его потомок (иначе 422); `null`/0 — основной снова сам трек |
| POST | `/jobs/{id}/overdub` | `{style, lyrics?, seed?, gain?, abc?}` → `{id}` — партия поверх трека: новый рендер по партитуре трека (или своему плану `abc` — так инструмент звучит только в выделенном куске) с новым стилем. Готовая партия подмешивается к оригиналу с громкостью `gain` (по умолчанию 0.5) в файл `overdub-<id>.flac`; `gain=0` — без смешивания (кавер новым треком). Сид родителя — та же интерпретация. Без `lyrics` модель поёт вокализ. Нет партитуры — 404 |
| POST | `/jobs/{id}/variant_track` | `{file, title?, voice_src?}` → `{id}` — вариант эффекта (`dsp-*.flac` и др.) отдельным готовым треком: копия звука и партитура исходника, дальше работают дорожки и эффекты (`parent_id` = исходник, `role=variant`). `voice_src` — трек, чей голос подставлен в версию (после «перепеть»); несуществующий — 422 |
| POST | `/jobs/{id}/voice` | ЭКСПЕРИМЕНТ «голос альбома»: `{ref_job_id, ref_from?, ref_dur?, steps?, title?}` → `{id}` — новая версия, где голос спет тембром образца (Seed-VC), музыка и мелодия прежние. Образец — окно дорожки голоса трека `ref_job_id`: `ref_from` (не задано — самый плотный кусок пения), `ref_dur` 3–30 с (25), `steps` 10–100 (50). Голос узнаётся, но дрожит. Seed-VC не установлен — 503 |
| POST | `/jobs/{id}/voice_preview` | ЭКСПЕРИМЕНТ «голос альбома», прослушать кусок: `{ref_job_id, from, to, ref_from?, ref_dur?, steps?}` → `{file, from, to}` — тот же перевод голоса тембром образца (Seed-VC), но только на куске `[from, to)` трека (3–30 с, иначе 422); файл `preview-vc-*.flac` в папке трека (хранятся 3 последних). Идёт в очереди видеокарты, отвечает, когда кусок готов. Нет Seed-VC — 503, трек или образец не готов — 404 |
| POST | `/tracks/import?transcribe=&title=` | Импорт своего трека (байты + `X-Filename`) → `{id, duration_sec, abc_file, transcribe_error}`. `transcribe` (по умолчанию да) — сразу снять партитуру для ролла и овердаба; её сбой трек не отменяет |
| POST | `/jobs/{id}/preview` | `{from_sec, to_sec}` (не короче 1 с) → `{file, from_sec, to_s, duration_sec}` — быстрый кусок трека из сохранённых латентов (без новой генерации), файл `preview-<от>-<до>.flac` |
| GET | `/jobs/{id}/previews` | Имена `preview-*.flac` трека, новые первыми |
| POST | `/jobs/{id}/mp3` | Сделать `audio.mp3` (320 кбит/с), если его нет (импортированные треки) → `{file}` |

### Тело POST /jobs

| Поле | Значение |
|---|---|
| `style` | Строка стиля — английские теги YuE (обязательно) |
| `lyrics` | Текст с секциями `[Verse]`, `[Chorus]`… или `[Instrumental]` (обязательно) |
| `title` | Название; пусто — «Untitled ЧЧ:ММ» |
| `seed` | Сид; пусто или 0 — случайный, он записывается в трек. С `parent_id` — сид родителя (у старого родителя без сида — 831001) |
| `cot` | Режим плана: `full` (по умолчанию) / `melody` / `off` |
| `abc` | Свой план (ABC). С `cot=off` — 422 |
| `draft` | Черновик ~15–20 с: послушать стиль до полного рендера |
| `arc` | Драматургия поверх плана: `build` (нарастание), `wave` (волна), `burst` (взрыв, голос на октаву выше в финале). Работает и со своим `abc`; с `cot=off` — 422 |
| `max_tokens` | Потолок длины (~25 токенов/с), не сама длина: у полного трека не меньше 6000, у «без слов» (`[Instrumental]`) — 1200 на секцию + 800; 0 — бюджет воркера |
| `temperature` | Смелость игры: 0 (по умолчанию 1.0) или 0.5–1.5 |
| `cfg` | Точность по стилю и нотам: 0 (по умолчанию 1.5, переменная `YUE2_CFG_SCALE`) или 1–4 |
| `parent_id`, `role` | Производный трек: от какого и зачем — `section` (кусок для вклейки), `rebuild`, `fragment`, `variant`. В приложении прячется под родителем. Нулевые `temperature`/`cfg` и пустой сид берутся у родителя. Продолжение создаётся только через `/continue` |
| `sound_preset_ids` | До 3 разных пресетов звука: их применит приложение, когда трек будет готов. С `draft` — 422 |

### Поля трека (GET /jobs)

Основные: `id`, `title`, `status` (`queued` / `running` / `done` / `error` / `canceled`), `style`, `lyrics`,
`seed`, `cot`, `draft`, `arc`, `temperature`, `cfg`, `duration_sec`, `audio_file`, `mp3_file`, `wav_file`,
`abc_file`, `error`, `folder`, `created_at`, `finished_at`.

| Поле | Значение |
|---|---|
| `parent_id`, `role`, `cont_from` | Производный трек и место продолжения |
| `head_id` | Основная версия песни (у корня) |
| `voice_src` | Трек, чей голос подставлен в версию; пусто — свой голос |
| `req_abc` | Трек рендерился по своему плану (`request.abc`) |
| `engine` | Чем сделан: `torch`, `cpp-bf16` / `cpp-q8` / `cpp-q6` / `cpp-q5`; пусто у старых — PyTorch. Сид повторяет исполнение только на том же движке |
| `has_draft` | У трека есть черновик студии — незаконченная работа (см. «Черновик студии») |
| `mixes` | Число готовых миксов студии (`overdub-inst-*.flac`: вклейки, эффекты на дорожки) |
| `sound_presets` | `[{id, status: pending/running/done/error, child_id, error}]` |
| `queue_pos`, `source` | Место в очереди и кто поставил |
| `vocal_leak` | Метка «в треке без голоса слышен голос» |
| `truncated` | Генерация упёрлась в бюджет и после одного автоповтора (×1,6): финал мог не прозвучать |
| `stage`, `tokens`, `tok_per_s`, `elapsed_s`, `progress_pct` | Живой прогресс — только у идущего трека |

## Партитура и разбор звука

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/jobs/{id}/score` | Таймлайн по `score.abc`: такты × голоса, аккорды, секции, громкость (RMS) по секциям |
| POST | `/jobs/{id}/plan_check` | `{abc, from_sec?}` — изменённый план против плана трека: такты по голосам было/стало, длина, изменённые такты (время, текст до и после), потолок голоса (верх мелодии + 2 ступени), предупреждения. Пустой `abc` — 422 |
| GET | `/jobs/{id}/chord_grid` | Аккорды и секции плана по тактам звука: `{bpm, bars: [{start, end, chord, section}]}` в секундах трека (доли — по барабанам, нет — по миксу). Нет плана — 404, нет долей — 422. Для синт-партии по аккордам |
| POST | `/jobs/{id}/grid` | `{from_sec, to_sec}` (0 — до конца) → `{bpm, offset, strength, source}` — темп и время сильной доли в окне, по дорожке барабанов (если есть) или миксу; `strength` < 0,1 — сетки по сути нет. Окно короче 4 с — 422 |
| POST | `/jobs/{id}/analyze?fresh=` | Замеры трека: темп, крест-фактор, динамика, спектр; кэш `metrics.json`, `fresh=true` — пересчитать |
| GET | `/jobs/{id}/tones?from=&to=&stem=` | Узкие устойчивые тона («свист», писк) в окне — в миксе или в дорожке `stem` (`vocals` / `drums` / `bass` / `other` / `guitar` / `piano`): `[{hz, prominence_db}]`, самый заметный первым, ≥ 12 дБ над окрестностью ±300 Гц, не больше 5; `to=0` — до конца. Нет дорожки — 409, окно вне трека — 422 |
| GET | `/jobs/{id}/vocal_contour?from=&to=` | Высота голоса по тактам плана (по дорожке `vocals`): `{bars: [{index, start, end, notes[4]}], median_hz, low_hz, high_hz}`, ноты по четвертям такта («D4», «·» — нет голоса). Нет дорожки голоса — 409 |
| GET | `/jobs/{id}/peaks?file=&bins=` | Огибающая громкости (волна студии): `{file, bins, duration_sec, peaks: [[min, max], …]}`, амплитуды −1…1. `file` пусто — основной трек; `bins` пусто — ~60 окон/с (500…20000 окон, кэш `<файл>.peaks.json`), явное — 100…20000 без кэша |
| GET | `/jobs/{id}/spectrum.png?file=` | Спектрограмма PNG 1600×320, ось X — 0…длительность (та же шкала, что у волны); кэш рядом с файлом. Нужен ffmpeg на воркере, нет — 503 |
| GET | `/jobs/{id}/guitar_part?style=` | Что сыграет гитарист «по аккордам плана» (блок `gtrnotes`): `{style, bars, strikes: [{t, midi[]}], beats, tune_cents}`. `style` — 0 авто, 1 бой, 2 перебор, 3 бас + аккорд, 4 квинты; иное — 422. Нужны план и дорожка гитары; кэш `guitar-part.json` |
| POST | `/jobs/{id}/transcribe` | Снять партитуру (SheetSage2) с готового трека без неё → `{id, abc_file}`. Партитура уже есть или трек не готов — 409 |

| Метод | Путь | Что делает |
|---|---|---|
| POST | `/references` | Эталонная запись (байты + `X-Filename`) → `{id, metrics}` — замеры для сравнения с треками. Не разбирается — 422 |
| GET | `/references` | Список эталонов `[{id, created_at, metrics, size}]`, новые первыми |

## Дорожки

| Метод | Путь | Что делает |
|---|---|---|
| POST | `/jobs/{id}/stems?model=` | Разделить трек → `{stems, seconds, model}`. Основные дорожки `stem-drums/bass/other/vocals.flac` в сумме дают трек. Подробные — `guitar`, `piano` (внутри «прочего») и, только у RoFormer, части барабанов `kick`, `snare`, `toms`, `hh`, `ride`, `crash` — в сумму не входят. `model` — `roformer` или `htdemucs` разово (иное — 422), без параметра — настройка `stems_model`. Сбой RoFormer — запасной путь htdemucs. Повторный запрос, пока трек уже делится, ждёт идущего разделения и отдаёт его итог |
| GET | `/jobs/{id}/stems` | Дорожки трека `[{file, name, created_at, metrics}]` |

## Варианты эффектов

Вариант — обработанная копия трека в его папке (`dsp-*.flac`, `overdub-*.flac`), с замерами и подписью.

| Метод | Путь | Что делает |
|---|---|---|
| POST | `/jobs/{id}/dsp?label=` | Загрузить вариант от приложения (байты, `X-Filename` вида `dsp-*.flac`); `label` до 300 символов — что сделано («Перегруз голоса · голос») → `{file, created_at, metrics, label}` |
| GET | `/jobs/{id}/dsp` | Варианты `[{file, created_at, metrics, label}]`, новые первыми |
| DELETE | `/jobs/{id}/dsp/{файл}` | Удалить вариант и его замеры, кэш волны и спектра → `{deleted}`. Дорожки `stem-*` так не удаляются — 422 |

## Звуковой движок

Обработка на воркере цепочкой блоков: педали, усилитель NAM, кабинет, пространство, сэмплеры, синт. Блоки
и их параметры — в [effects.md](effects.md) и в MCP-инструменте `fx_blocks`. Блоков 24: `gate`, `eq`, `comp`,
`drive`, `amp`, `cab`, `reverb`, `delay`, `gain`, `sampler`, `bass`, `synth`, `chorus`, `phaser`, `flanger`,
`tape`, `spring`, `tremolo`, `perc`, `glue`, `limiter`, `air`, `gtrnotes`, `level`.

| Метод | Путь | Что делает |
|---|---|---|
| POST | `/jobs/{id}/fx` | Цепочка на трек или дорожку → вариант `dsp-fx-<дорожка>-<хэш>.flac` (как у `/dsp`, плюс `clipped`). Тело — ниже. Звук не сдвигается во времени; блок `amp` идёт через очередь. Неверная цепочка — 422 с причиной; движок выключен (`fx_engine` или `PARTSCASTER_FX_ENGINE=0`) — 503 |
| GET | `/fx/assets` | `{amps: [{name, latency}], irs: [{name, sr, seconds}], kits: [{name: «osdk/kick», samples}]}` — захваты усилителей NAM, импульсные отклики (IR) и установленные наборы сэмплов |
| POST | `/fx/assets?kind=amp/ir&name=` | Загрузить `.nam` (`kind=amp`) или `.wav` (`kind=ir`), байты в теле, до 50 МБ → `{name, kind}`. Больше — 413, не тот формат или имя — 422 |
| POST | `/fx/kits/install?name=` | Поставить набор сэмплов из каталога ниже → `{name, parts, downloaded}`. Повтор — без сети, недостающие части докачиваются. Неизвестное имя — 422, сбой сети — 502 (полунабор не остаётся) |
| GET | `/fx/kits/progress` | Идущая установка набора `{name, part, done, total, bytes}` или `{}` |
| GET | `/fx/phrases` | Фразы страницы «Инструменты»: `[{id, family: guitar/bass/drums/synth, name: {ru, en}, bpm, beats, chords, style, parts, cycle_sec}]`. Гитара — записями (GuitarSet, CC BY 4.0), бас и барабаны — нотами; `synth` — тишина, ноты блоков `synth`/`perc` кладёт клиент по тактам круга |
| POST | `/fx/phrase` | `{phrase, tempo 0.5…1.5 (1), chain, stems (части под цепочку, пусто — все), bypass}` → `{file, cycle_sec, clipped}` — круг фразы через цепочку, играет по кругу без шва (хвосты конца круга — в его начале), громкость — по сухой фразе. `bypass` оставляет только блоки `synth`/`perc`. Последние 40 кругов кэшируются. Нет фразы — 404, неверный темп, цепочка или часть — 422, движок выключен — 503 |
| GET | `/fx/phrase/files/{файл}` | WAV 16 бит стерео круга (имя — из ответа `/fx/phrase`) |
| GET | `/fx/instruments` | Свои инструменты `[{id, name, base, group, stems, chain, extra, created_at}]` |
| POST | `/fx/instruments` | `{name 1…80, base (id готовой цепочки), group ≤ 40, stems (непустой: дорожки, `synth`, `perc`), chain, extra {style, octave, pattern, swing, accent, amp_hint, place}}` → созданный; неверное — 422 |
| PUT | `/fx/instruments/{id}` | Переданные поля заменяются → обновлённый; нет такого — 404 |
| DELETE | `/fx/instruments/{id}` | → `{ok}`; нет такого — 404 |

### Тело POST /jobs/{id}/fx

| Поле | Значение |
|---|---|
| `source` | `mix` (по умолчанию) или дорожка: `vocals`, `drums`, `bass`, `other`, `guitar`, `piano`, `kick`, `snare`, `toms`, `hh`, `ride`, `crash`. Дорожек нет — делаются |
| `chain` | Массив блоков `[{type, …параметры}]` по порядку; пропущенные параметры — по умолчанию |
| `from`, `to` | Окно, с; вне окна трек не меняется |
| `output` | `mix` — трек, где дорожка заменена обработанной; `solo` — только обработанная дорожка |
| `label` | Подпись варианта |
| `preview` | Только прослушать кусок (нужны `from` и `to`): файл `preview-fx-<хэш>.flac` — окно плюс хвост реверба/дилея до 3 с, без замеров, в варианты не попадает; тот же запрос — тот же файл без пересчёта; на трек хранится до 8 таких файлов → `{file, duration_sec, clipped}`. С `limiter` громкость считается по всему входу, потом режется окно |
| `fade` | Только превью: плавные края входа окна, 0…0,5 с |
| `pad` | Только превью: файл от начала трека (до `from` — тишина), чтобы вставить его без сдвига |
| `add` | Добавление (синт-партия): `output=mix` — трек плюс обработанное, ничего не вычитается; ноты `synth` — в секундах трека, воркер сдвигает их на окно |
| `file` | Вход — вариант трека (`dsp-*.flac` или `overdub-*.flac`), а не исходный звук; только с `source=mix`. Неверное имя — 422, нет файла — 404 |
| `in_place` | С `file`, не превью: результат записать в тот же вариант (к подписи « · мастер») — мастер на готовом миксе студии |

## Пресеты звука

Пресет — рецепт обработки трека целиком: правки дорожек, финал на микс, мастер. Встроенных 109: три
настроенных по трекам (`transmission`, `sex-on-fire`, `live-rhythm`) и жанровые; поле `family` — Рок,
Тяжёлое, Электроника, Поп и другое. Встроенные идут первыми, при старте воркера обновляются из кода (id
прежний) и не меняются через API.

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/sound-presets` | `[{id, slug, name, note, family, specs, final, master, parts, reference_job_id, target_lufs, builtin}]` |
| POST | `/sound-presets` | Создать свой → пресет с `id`. Тело — ниже; пустой пресет и другие ошибки — 422 с причиной |
| PUT | `/sound-presets/{id}` | Заменить свой целиком (тело как у POST). Встроенный — 409, нет такого — 404 |
| DELETE | `/sound-presets/{id}` | Удалить свой → `{deleted}`. Встроенный — 409, нет такого — 404 |
| POST | `/jobs/{id}/sound-presets/{pid}/state` | `{status, child_id?, error?}` — статус пресета у трека (его применяет приложение): `pending→running` (захват; уже не `pending` — 409), `running→done` (`child_id` — версия), `running→error` (`error` до 500 символов), `error`/`running→pending` (повтор); прочие переходы — 409, нет поля — 422, у трека нет пресета — 404. Ответ — `sound_presets` трека |

### Тело пресета

| Поле | Значение |
|---|---|
| `name` | Название, 1–80 символов |
| `note` | Описание звука |
| `specs` | До 16 правок дорожек на весь трек: `{stems: [дорожки], db −24…24}` и ровно одно из: `engine` (цепочка движка, проверка как у `/fx`), `chain` + `params` (эффект ffmpeg), `steps: [{chain, params, off}]` (до 12 педалей). Дорожки: `vocals`, `drums`, `bass`, `other`, `guitar`, `piano`, `kick`, `snare`, `toms`, `hh`, `ride`, `crash`. Запись `{stems: [одна], level_db}` — только громкость; `{stems: [одна], place: {pan −1…1, width 0…2}}` — место в стерео |
| `level_db` | У записи одной дорожки, −40…+6 — цель громкости дорожки к треку: при применении приложение подстраивает громкость по замеру (±12 дБ; с обработкой — по замеру обработанной; после мастера сверяет итог и делает до двух исправляющих пересборок) |
| `final` | До 12 шагов `{chain, params, off}` на весь микс после правок (ffmpeg) |
| `master` | Цепочка движка до 16 блоков на весь микс на воркере после финала |
| `target_lufs` | −24…−6 или `null` — громкость результата: ложится в `limiter` мастера (истинный пик −1 dBTP; нет `limiter` — дописывается) |
| `parts` | До 8 партий поверх трека: `{kind: synth/perc, engine (первый блок synth или perc, без нот), style: pad/arp/pulse/drone, octave −2…2, pattern: fours/eighths/sixteenths/backbeat/offbeat, swing 0…0,5, accent 0…1, sections, place}`. Ноты строит приложение по аккордам (`chord_grid`) и сетке трека |
| `reference_job_id` | Трек-эталон, по которому настраивался пресет |

## Черновик студии

Незаконченная работа над треком: правки студии («Изменения трека»: вклейки, эффекты на дорожки, педали, движок,
громкости, место, мастер) и ожидающие рендеры кусков. Пишет приложение; содержимое `state` воркер не разбирает
(JSON-объект до 1 МБ). Черновик удаляется вместе с треком и после «применить всё» в студии.

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/drafts` | Все черновики `[{job_id, state, updated_at}]` |
| GET | `/jobs/{id}/draft` | Черновик трека `{job_id, state, updated_at}`; нет — 404 |
| PUT | `/jobs/{id}/draft` | `{state}` → черновик; нет трека — 404, `state` не объект или больше 1 МБ — 422 |
| DELETE | `/jobs/{id}/draft` | → `{deleted}` |

## Журнал правок и рецепты

Журнал — что сделано с треком; рецепт — песня правилами без аудио, чтобы повторить её на другой
установке. Журнал пишут приложение и MCP после успешной правки, импорт рецепта ведут они же шаг за шагом;
воркер хранит только состояние.

| Метод | Путь | Что делает |
|---|---|---|
| POST | `/jobs/{id}/ops` | `{op, params, result, refs}` → `{id}` — запись журнала. `op`: `submit`, `continue`, `fragment`, `overdub`, `variant_track`, `fx`, `minus` (старые рецепты: при импорте шаг пропускается), `update`, `set_head`, `rebuild_sections`, `envelope`, `splice`, `dsp_apply`, `pedals`, `sound_preset`; иное — 422, нет трека — 404 |
| GET | `/jobs/{id}/ops` | Журнал трека по порядку `[{id, job_id, op, params, result, refs, created_at}]` |
| GET | `/jobs/{id}/recipe` | Рецепт всей песни трека (от корня). 422 — цепочка версий оборвана удалённой версией или в песне есть то, что рецептом не переносится (черновик, импорт чужого аудио, «голос альбома») |
| POST | `/recipes/import` | `{recipe, mode: seed/plan}` → `{id}` — новая сессия импорта; чужой формат — 422 |
| GET | `/recipes/imports` | Сессии импорта `[{id, title, status, progress, error, mode, root_job_id, created_at, finished_at}]` |
| GET | `/recipes/imports/{id}` | То же плюс `recipe` и `state` ведущего |
| POST | `/recipes/imports/{id}/claim` | `{owner}` → `{id}` — взять ведение на 10 мин; держит другой — 409 |
| PATCH | `/recipes/imports/{id}` | `{owner?, state?, progress?, status? (running/done/error/dismissed), error?, root_job_id?}`; импорт ведёт другой — 409 |
